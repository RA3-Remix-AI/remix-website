## 重新生成

需要本机 ffmpeg / ffprobe（本轮 ffmpeg 8.1，包含 libx264）。执行 `node scripts/optimize-home-media.mjs`。脚本只用于素材制作，正常网站构建不需要 ffmpeg。

未压缩母版已保存在 Git 忽略的 `intro-video/out/home-media-masters-2026-10-28/`，不随静态站点部署。首次在另一台机器重做时，需先从原制作资料或优化前 Git 版本恢复四个源视频；脚本随后会备份母版。输出名称来自实际内容哈希；更换编码器版本可能改变输出哈希，重新生成后需按新清单更新 `commanders.ts` 与 `ArrivalIntro.tsx` 的路径，移除旧交付派生文件再部署。

移动端只应请求 `videoMobile`，桌面只请求 `video`；不要通过两套同时挂载的 `<video src>` 来选择画面，避免两套文件一起下载。静态图与视频的来源未改变，图像和游戏版权归属沿用原声明。
